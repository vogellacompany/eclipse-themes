vogella Eclipse Themes

Seven themes for the Eclipse IDE: GitHub Dark, Dracula, One Light, Nord, Gruvbox Material, AI Neon and VS Code Dark.

Update site

https://vogellacompany.github.io/eclipse-themes/

Install

  1. In Eclipse, open Help > Install New Software...
  2. Paste the update site URL into Work with and press Enter.
  3. Select vogella Eclipse Themes, and optionally vogella Theme Icon Sets for icons that follow the theme (Eclipse 2026-03 or later), finish the wizard and restart.
  4. Pick a theme in Window > Preferences > General > Appearance.
